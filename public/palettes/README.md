# Palette Images

These 7 images are used as drape overlays in the Color Family Diagnostics module.

## What they look like

Each image should look like the "Natural color palette" reference:
vertical color stripes, side by side, no labels, no borders.
Similar format: square or slightly portrait, ~600×600 px minimum.

## Files needed

Place these files in this folder:

| File | Colors to include |
|------|------------------|
| `warm.webp` | dark brown, olive green, camel, terracotta, rust/burnt orange |
| `cool.webp` | lavender, slate grey, dusty rose, steel blue, icy pink |
| `bright.webp` | vivid coral, cobalt blue, bright emerald, hot fuchsia, clear yellow |
| `muted.webp` | dusty mauve, sage green, greyed teal, muted peach, soft caramel |
| `light.webp` | blush pink, powder blue, soft ivory, pale lavender, light mint |
| `deep.webp` | deep plum, forest green, chocolate brown, burgundy, navy |

Note: neutrals are no longer a palette image — they are interactive color circles with AI comments. No `neutrals.webp` needed.

## Format

- WebP preferred (smaller file size), JPG or PNG also fine
- Rename to exact filenames above
- Vertical stripes work best (like the reference image)
- No text, no labels, no borders on the image itself
- Width per stripe: equal, all same width
